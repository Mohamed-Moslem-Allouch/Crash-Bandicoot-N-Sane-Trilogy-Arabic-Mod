## 📦 Download & Installation / التحميل والتثبيت

### Option 1 — Quick Download (`.rar`)
Download [`Crash_Bandicoot_Arabic_Mod.rar`](Crash_Bandicoot_Arabic_Mod.rar), extract the files into your game folder (next to `CrashBandicootNSaneTrilogy.exe`), and double-click:
- **`Install_Arabic_Mod.cmd`** — Installs the Arabic mod immediately with no prompts.
- **`Uninstall_Arabic_Mod.cmd`** — Restores the original English files cleanly.

### Option 2 — Direct Files (`Crash_Bandicoot_Arabic_Mod/`)
Copy the contents of [`Crash_Bandicoot_Arabic_Mod/`](Crash_Bandicoot_Arabic_Mod/) (`_Arabic_Mod/`, `Install_Arabic_Mod.cmd`, `Uninstall_Arabic_Mod.cmd`) into your game folder and run `Install_Arabic_Mod.cmd`, **or** manually copy `_Arabic_Mod/update.pak` into `<Game Folder>/archives/update.pak`.

> **Important / مهم:** Make sure the game language is set to **English** in Steam / emulator settings, since the mod patches the English localization strings (`*_en.lng`) with full shaped Arabic text and custom Arabic bitmap fonts.
